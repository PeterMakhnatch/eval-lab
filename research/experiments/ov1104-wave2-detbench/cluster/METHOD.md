# Exploratory task-cluster bootstrap

Use only the five admitted DEV sets from the manifest, the five selected signal files, the frozen matrix, and recorded replay decisions. Reconstruct the four exact-matrix decisions using the existing scorer and published 5% final thresholds. The scorer derives component ranks and OR cutoffs once on the original DEV cohort, exactly as in exact_matrix.py. Freeze all decisions before resampling. Review is not keep. Missing combined scores are not kept.

Cluster by the manifest's `cluster` within each corpus; identical names across corpora are separate clusters. For each of 5000 replicates, draw the original number of task clusters with replacement independently within each corpus. Include all runs in each selected cluster, with multiplicity. Use these same draws for each method and for pooled estimates. Pooled estimates add counts across the five corpus-stratified draws. Use seed 110406 and Python's random.Random; sort corpus and cluster names before drawing.

For each method and corpus or pooled group, calculate kept cheat runs divided by all kept runs. Exclude draws with zero kept for that method and group; report valid and excluded draws. Calculate the 2.5th and 97.5th percentiles by linear interpolation at index (n-1)*p. If no valid draws exist, the interval is null. Report the original point counts, Wilson 95% interval treating runs as independent, and the number of task clusters. Validate all point counts against the existing baseline and exact-matrix aggregate outputs.

Before computing results, hash this document, the analysis code, the manifest and signal bytes, matrix, scorer dependencies, replay decisions, and comparison outputs. Hashing whole files does not parse non-DEV records. Verify hashes again after computation. The selected DEV cohort is not a production sample. Clusters are assumed independent; few clusters, zero-kept draws, corpus selection, repeated use of DEV for selection and fitting, missing component handling, and conditioning on the frozen fitted rules limit inference. The bootstrap does not account for threshold fitting, model selection, or uncertainty outside these observed corpora.
