What this is

Observation: Eval Lab is a local evaluation R&D workbench around Harbor. Harbor executes and verifies. This repo owns specs, the policy queue, immutable jobs, a rebuildable catalog, Parquet facts, and human approval.

Inference you should reject: that it is already a post-training data platform. There is no registered held-out suite, no Zone-04 export product, and no training loop. That is a staged goal (docs/path-forward-2026-08.md S0–S5), not present tense.
