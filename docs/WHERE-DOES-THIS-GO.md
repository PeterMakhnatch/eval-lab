# Where Does This Go? File Placement Decision Guide

This decision tree specifies the authoritative destination for every file type across `eval-lab`.

---

│

## 2. Directory Matrix & Ownership Rules

| Path Pattern | Category | Retention & Authority Policy | Primary Subsystem Owner |
|---|---|---|---|
| `src/evallab/schemas/` | Code / Contracts | Permanent versioned source | Schemas & Contracts |
| `src/evallab/storage/` | Code / Storage | Permanent versioned source | Storage & Compaction |
| `src/evallab/evidence/` | Code / Evidence | Permanent versioned source | Evidence Projection |
| `src/evallab/interpretation/` | Code / Analysis | Permanent versioned source | Interpretation & Judgment |
| `src/evallab/recovery/` | Code / Recovery | Permanent versioned source | State Recovery |
| `src/evallab/*.py` | Code / Core | Permanent versioned source | Platform & Runners |
| `library/tasks/` | Task Packages | Permanent versioned task definitions | Builder / Registry |
| `research/experiments/` | Specs | Declarative experiment treatment plans | Analyst / Runner |
| `runs/trial_jobs/` | Zone 1 Evidence | Ephemeral local raw evidence (gitignored) | Runner / Harbor |
| `derived/evidence-cas/` | Zone 1 CAS | Durable content-addressed store (gitignored) | Storage (`evidence_store`) |
| `research/evidence/runs/` | Golden Evidence | Tracked golden controls (committed) | Analyst |
| `derived/parquet/` | Zone 3 Lake | Rebuildable columnar lake (gitignored) | Storage (`parquet_compaction`) |
| `docs/` | Documentation | Permanent versioned docs | All Domains |
| `docs/repo-map.md` | Generated | Generated by `python -m evallab.repomap generate` | Navigation (`repomap`) |
| `docs/INDEX.md` | Generated | Generated by `python -m evallab.docindex generate` | Navigation (`docindex`) |
| `docs/STATUS.md` | Generated | Generated by `evallab status --update` | Operations (`status`) |
| `tests/` | Tests | Permanent focused unit & regression tests | All Domains |

## 3. Invariants & Common Misplacements

1. **Never commit raw trial runs to `runs/`:** Use `runs/` for local scratch runs. To promote golden baseline controls, place them in `research/evidence/runs/`.
2. **Never hand-edit generated docs:** Files containing `<!-- generated-by: ... -->` must be updated using their respective generator commands.
3. **No circular imports:** Domain schemas in `src/evallab/schemas/` must never import heavy database or execution engines.
4. **Use `evallab.storage.paths`:** Always resolve data, execution, and artifact directories through `evallab.storage.paths` instead of hardcoding relative paths.
