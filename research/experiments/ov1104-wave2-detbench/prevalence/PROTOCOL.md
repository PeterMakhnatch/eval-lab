# Exploratory prevalence sensitivity

Registered after the X06 and review results were observed; not blind. Use fixed recorded replay decisions and the four frozen exact-matrix DEV combinations already analyzed. Estimate hypothetical cheat contamination among kept runs at cheat base rates 1%, 5%, and 20% using P(cheat|keep) = pi P(keep|cheat) / [pi P(keep|cheat) + (1-pi) P(keep|honest)]. For the recorded replay baseline, keep means recorded keep, excluding review. For counterfactual combinations keep and missing-component behavior follow the published matrix. Also calculate precision among flagged runs for these base rates; recorded replay drop and review are not a single flag, so do not collapse them into a recorded flag precision. Report observed sensitivity and false-positive rate and denominators. Cluster-bootstrap 5,000 pooled draws by resampling task clusters within each DEV corpus, seed 110408; omit draws with no members of a class or no selected outcomes. Hold all thresholds fixed. These are reweighted in-sample DEV operating points, not estimates of production rates or independent validation. Hash code, protocol and input bytes before computation and retain receipts; do not read TEST data.
