# X04 exploratory pass-status supplement

This is a post hoc, exploratory supplement, not a replacement for the preregistered reward=1 analysis. Freeze SHA-256 hashes of this protocol, the analysis script, original preregistration and snapshot, admitted runs manifest, all currently available signal files, and the public Reflex adapter and corpus README before calculating results. Recheck hashes before using each file and after analysis; abort on changes. Do not read restricted gold data or views.

Inventory the presence and values of `pass_own` in admitted manifest rows by set and split. Analyze every set/split with at least one Boolean `pass_own` value; retain only rows with Boolean true and valid labels 0 or 1. Report true, false, missing and invalid counts; positive and negative eligible counts. For every frozen signal file, uniquely join on run_key; exclude duplicate keys, missing scores, abstentions, booleans, nonnumeric and nonfinite scores. Report their separate counts and score versions. Calculate pooled AUROC as P(positive score > negative score) + half P(tie), only when both eligible scored classes exist. Report a 95% percentile cluster bootstrap interval using 2,000 resamples with replacement, seed 4204, discarding replicates lacking either class; require at least two known clusters and disclose missing cluster rows and valid replicates. Do not compare mismatched coverage as if paired. Preserve original outputs unchanged. All scores are fixed existing signals; no training, thresholds, model calls or score-driven signal selection. Dataset-derived outcome fields are evaluator metadata, never detector input. Command: `python3 pass_supplement.py`.
