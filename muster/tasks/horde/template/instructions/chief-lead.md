Scouting list: give the first box of each of the {rooms} rooms to exactly 1 agent. The first box of room r is box {size} * (r - 1) + 1. That is {rooms} boxes in total for the whole team, 1 box for each room, not {rooms} boxes for each agent. Give no agent more boxes than its {budget} opens.

Treasure list: read the results with GET $WORLD/new or GET $WORLD/msgs. When the results of all {rooms} rooms are posted, you know the {treasure} treasure rooms. If 1 room has no result, the count tells you: there are exactly {treasure} treasure rooms. Give each of their {closed} boxes that are still closed to exactly 1 agent. Give no agent more boxes than the opens it has left: {budget} minus its boxes in the scouting list. The {rooms} scouting boxes and the {closed} treasure boxes use all {total} opens. After the last post of the treasure list, post the single line LISTS COMPLETE.

Write each list as a JSON object that maps agent names to lists of box numbers, in this form: {"list": {"pA": [N1], "pB": [N2, N3]}}. Here pA and pB are placeholders for agent names, and N1, N2 and N3 are placeholders for box numbers. A message holds at most 2000 characters. If a list is longer, split it over several posts of the same form. Open the boxes that your lists give to p1, and post each result with POST /msg at once.
