# Eval Lab Canonical Glossary & Terminology Guide

This glossary defines canonical terms, code carriers, overloaded senses, and strict disambiguation rules across the evaluation lifecycle. It enforces precision without renaming existing APIs.

## 2. Disambiguation of Overloaded Terms

### A. Senses of `manifest` (7 Senses)
1. **Campaign Analysis Manifest:** (`src/evallab/interpretation/trajectory_runtime.py:208`) Schema `campaign-analysis-manifest/v1` specifying cohort/accounting items for batch trajectory analysis.
2. **Cross-Campaign Analysis Inventory / Manifest:** (`src/evallab/interpretation/trajectory_data_quality.py:1429`) Aggregated collection of trial references across multiple campaigns.
3. **Artifact / Run Evidence Manifest:** (`src/evallab/results.py:46`) `manifest.json` inside a trial or job `artifacts/` folder enumerating logged output files.
4. **Parquet Compaction Manifest:** (`_MANIFEST.json` in catalog tables) Directory-level metadata index tracking compacted Parquet partitions.
5. **Benchmark / Task Definition Manifest:** (`task.toml` or `PROVENANCE.json`) Task configuration specifying environment setup, tests, and evaluator rules.
6. **External Dataset Export Manifest:** Manifests associated with external corpus exports (e.g., Exa / ATIF datasets).
7. **Package / Workspace Dependency Manifest:** Standard project build files (`pyproject.toml`, `uv.lock`).

### B. Senses of `status` & `ANALYSIS_READY` (5 Carriers)
1. `TrajectoryQualityReport.is_analysis_ready` (`trajectory_quality.py:143`): Boolean indicating trial quality is `pass` or `warn` without fatal anomalies.
2. `EvidenceCoverageMetrics.analysis_ready` (`evidence_pack.py:104`): Boolean verifying required construct coverage elements exist for model pack generation.
3. `TrialReadinessRecord.is_analysis_ready` (`trajectory_readiness.py:42`): Comprehensive readiness indicator combining IR integrity and data quality.
4. `CoverageStatus` Literal (`trajectory_semantics.py:916`): Enum (`present`, `missing`, `partial`, `not_applicable`) for individual semantic constructs.
5. `EvidenceCoverage.analysis_ready` (`semantic_facts.py:182`): DuckDB/Parquet projected boolean for mart querying.

### C. Senses of `frozen` (6 Senses)
1. **Pydantic / Dataclass Model Immutability:** Python `@dataclass(frozen=True)` or `ConfigDict(frozen=True)`.
2. **Contract / Schema Version Lock:** "v1 contract locked" — schema version is fixed and backward-incompatible changes require a new versioned schema.
3. **Interface Freeze / Execution Blocked:** Operational moratorium on running capability evaluations pending calibration.
4. **Protocol / Seed / Rubric Freeze:** Fixed experimental configuration for deterministic replication.
5. **Gym Environment Freeze:** Containerized snapshot state of evaluation environments (`test_gym_freeze.py`).
6. **Human Baseline Calibration Freeze:** Frozen dataset of multi-rater labels used as an immutable gold standard.

## 3. Documentation Guidelines (Preserving Code Contracts)

1. **`TrialBundle` $\rightarrow$ `TrialRecord` / `durable evidence directory`:**
   - `TrialBundle` has no code representation. Reference `TrialRecord` for Python/SQL execution rows or `durable evidence directory` for on-disk runs. Do not alter code symbols.
2. **CLI Parameter `analyze batch <inventory>` $\rightarrow$ `analyze batch <manifest>`:**
   - Although the CLI argument is named `inventory` (`cli.py:3298`), the underlying schema loaded is `CampaignAnalysisManifest` (`trajectory_runtime.py:1921`). Documentation clarifies that this parameter takes a campaign analysis manifest file.
3. **Clear Contract States:**
   - Prefer specific descriptions like `v1 contract locked` or `disposition: HOLD` over unqualified terms like `FROZEN`.
