1. Current State & Purpose

What is this repo? It is an evaluation and research workbench for AI coding agents. Rather than building another chatbot or another agent harness, eval-lab sits around Harbor to make agent trials scientific, reproducible, and analyzable.

What can it do well right now?

  • Sandboxed Execution: Runs tasks safely in Docker via Harbor without touching host workstation files.
  • Dual Evidence Capture: Retains complete raw ATIF event traces (, tool calls, stdout) + environment truth (verifier outputs, git diffs, artifacts).
  • Dual-Store Ingestion: Projects raw JSON runs into PostgreSQL (metadata index) and Parquet (columnar step analytics) in a single command.
  • Zero-Overhead SQL Analytics: Uses DuckDB to query step-level agent behaviors across thousands of runs in milliseconds.
  • Trace Observability: Ships OTel spans directly to Arize Phoenix for visual trace debugging.
  • Autonomous Research Loop: 24/7 researcher agent loop (Autopilot) that analyzes failed runs and submits new hypothesis specs to an approval-gated queue.
