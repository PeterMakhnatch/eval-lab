# Replay Proof of the Live Loop: Throughput, Crash Recovery, Cost, Queue Composition (B2-REPLAY-PROOF)

This experiment evaluates the production factory opt-in AutoReview stage (HAR-B1-HOOK) under realistic load and adversarial conditions across 404 admitted DEV runs (304 Terminal Wrench DEV runs + 100 Goodfire deep_swe DEV runs).

## Artifact Inventory

- `compute_receipts.py`: Verification and summary computation script reading durable receipts and computing exact metrics, Wilson intervals, and cost projections.
- `summary.json`: Summary output generated by `compute_receipts.py`.

## Core Findings

1. **Crash Recovery & Idempotency**:
   - **Gate Verdict**: **PASS**.
   - Under 3 seeded `kill -9` terminations during active processing, recovery was exact:
     - Served requests set-equality: 19/19 (100% matched, zero discrepancy).
     - Duplicate served requests: 0.
     - Lost requests: 0.
     - Judge Station queue set-equality: 17/17 (100% matched, zero duplicate run IDs).

2. **Runtime Guards**:
   - **Kill Switch** (`<root>/autoreview.disable`): 100% of pending requests failed cleanly with error `kill_switch: autoreview.disable exists`.
   - **Hourly Rate Limit** (`--autoreview-max-per-hour`): First 2 requests served, subsequent 3 failed cleanly with error `rate_limited: 2 calls in past hour >= limit 2`.
   - **USD Budget Guard** (`--autoreview-max-usd`): Requests halted once cumulative spend crossed budget ($0.0100 >= $0.0050), failing subsequent requests with `budget_exceeded`.

3. **Throughput and Latency**:
   - Replay throughput over 404 runs (28,490 prefix scores): **17,234.0 events/min** (cached) vs **17,994.5 events/min** (off).
   - Per-prefix deterministic scoring latency (p50): **0.54 ms** (cached) vs **0.56 ms** (off).
   - Supervisor cycle time (p50): **0.063 s** (cached) vs **0.058 s** (off) during active replay (+8.6% L0 slowdown during replay).

4. **Triggers and Queue Dynamics**:
   - Total triggers requested across 404 DEV runs: 408 (246 unique runs triggered, 60.89%).
   - Trigger breakdown:
     - `l0_gate`: 163 triggers (40.35% of runs, 95% Wilson: 35.6%–45.3%).
     - `cascade_stage1`: 147 triggers (36.39% of runs, 95% Wilson: 31.8%–41.2%).
     - `target_surface`: 98 triggers (24.26% of runs, 95% Wilson: 20.3%–28.8%).
   - Resulting Judge Station queue: 246 unique entries (86 High priority 2, 75 Medium priority 1, 85 Normal priority 0).

5. **Live Model Attestation & Economics**:
   - Live slice served on `google-antigravity/gemini-3.8-flash`: 11 cards, 100% attested, 0 fallbacks.
   - Mean tokens per card: 6,998.8 tokens (~7.0k tokens).
   - Mean latency: 2.62 s (p50).
   - Cost projection per 1,000 runs (L0-only trigger rate = 403.5 cards / 1k runs):
     - `google-antigravity/gemini-3.8-flash` (Subscription): **$0.00**
     - `google-antigravity/gemini-3.8-flash` (Metered API): **$2.27**
     - `openai/gpt-4o` (Reference: $2.50 / 1M input, $10.00 / 1M output): **$9.18**
     - `anthropic/claude-3-5-sonnet` (Reference: $3.00 / 1M input, $15.00 / 1M output): **$11.86**
