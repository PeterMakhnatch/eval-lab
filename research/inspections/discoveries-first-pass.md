## Loop trustworthiness

The loop has useful safeguards: the analyst and synthesizer receive bounded JSON, are told not to invoke tools, must return structured output, and can cite only paths in an allow-list ([prompts](../../src/evallab/researchers.py#L893-L937), [validator](../../src/evallab/researchers.py#L1193-L1196)). Its critical gap is semantic validation: the models receive catalog summaries and path strings rather than file contents, `_validate_citations` checks only string membership, and `DiscoveryJournal` appends those links without checking existence, hashes, or whether the cited content supports the sentence ([prompt payload](../../src/evallab/researchers.py#L893-L917), [journal writer](../../src/evallab/researchers.py#L1087-L1104), [validator](../../src/evallab/researchers.py#L1193-L1196)).

The emitted proposal is instead a bounded, one-attempt Codex run on `event-summary`; it does not repeat the synthesis's stale html-js-filter suggestion, but it omits task and verifier digests even though the analysis contract requires them to define a comparable cohort ([runtime proposal](/Users/petermakhnatch/Developer/eval-lab/.worktrees/autopilot/queue/proposed/codex-01KZZCN7X9PA643W1QCKQNNNY5.json), [runtime synthesis](/Users/petermakhnatch/Developer/eval-lab/.worktrees/autopilot/queue/researchers/passes/2026-08-15/01KZZCK33HJM4R8HW3V0Y25DXE/synthesis.json), [cohort requirements](../../docs/analysis-loop.md#stage-3-define-a-cohort)). Until the loop persists immutable source references, validates cited contents, exposes the actual denominator/selection rule, and carries the fixed digests into the executable proposal, a human must independently reopen the evidence before accepting a discovery or spending against its proposal ([state machine review gate](../../docs/analysis-loop.md#state-machine)).
