# `tb21-weak-tests-v1`: TB2.1 weak-test catalog

`qa.answer_key/v1` catalog built by applying the existing Eval Lab
ref-subset + changed-line mutation method (`evallab hack ref-subset`,
native shared-verifier route) to the full 89-task reference-bearing
cohort of `harbor-framework/terminal-bench-2-1@7131e437`.

## Result

- **5 of 89 tasks confirmed weak** (observed full-cohort lower bound
  5.6%): `cobol-modernization`, `make-mips-interpreter`,
  `multi-source-data-merger`, `sam-cell-seg`, `sqlite-db-truncate`.
  14 independently graded witnesses in `findings.jsonl`.
- Every other task is `unknown`, never a clean negative:
  31 measured with no survivor, 6 measured with survivors that
  instruction adjudication rejected (equivalent / not consumed /
  optional-or-unclear), 2 infrastructure-unavailable, and 43 not run
  under recorded holds (resource, safety, local-model, incomplete
  reconstruction, opaque single artifact, external prerequisite).

## Method (as executed)

For each admitted task, on fresh native Docker sandboxes at the
task's declared timeout (1x) and resources, with shared admission
(at most two containers):

1. Original reference must score 1; actual no-reference base must
   score 0; a from-base reconstruction of only the selected output
   files must score 1 (no reference replay).
2. The existing greedy ref-subset search (≤24 grades) tries dropping
   reference blocks; the changed-line mutation pass (≤8 mutants,
   seed `tb21-weak-tests-v1`, revert-hunks excluded) mutates lines
   the reference wrote.
3. A surviving mutant becomes a finding only after literal
   instruction + verifier-consumer adjudication confirms a required
   behavior/value escapes the verifier.

The subset arm produced no confirmed weakness on this cohort (all
measured subsets either needed every block or had a single block);
all 14 witnesses come from the changed-line arm.

## Files

- `cohort.json` / `selection-splits.json`: frozen 89-task
  denominator, package digests, and pre-registered split labels
  (23 dev / 53 test / 13 heldout; historical TB dev exposure kept
  in dev). Splits are bookkeeping: sources were visible during the
  search, so this is not an independent held-out detector score.
- `atlas.jsonl`: one row per task with search status, targets,
  adjudications and, for confirmed tasks, bound witnesses.
- `evidence/<task>-<mutant>/`: per-control native matrix receipts,
  trial results, host-isolation records, oracle logs and graded
  scripts. `build.py` revalidates every digest and cross-checks
  reward, staged package, timeout and isolation before publishing.
- `items.jsonl` / `findings.jsonl` / `summary.json`: generated by
  `build.py` (rebuild / verify with `--check`).

## Limits

Text/data outputs without Python/JSON/C-family line support could
receive subset search but no line mutants; stateful or compiled
outputs that a selected-file patch cannot honestly reconstruct were
left unmeasured rather than proxied by post-oracle overlays.
Two tasks (`extract-elf`, `model-extraction-relu-logits`) repeatedly
hit native trial infrastructure failures and remain unknown.
No paid calls, no Codex CLI, no cloud execution were used.
