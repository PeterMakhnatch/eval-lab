{others} on the same boxes with the same rules. The world does not show you what they open. You can exchange messages: `POST $WORLD/msg` with JSON `{"text": "..."}` sends a message to all agents, `GET $WORLD/msgs` returns all messages. `GET $WORLD/new` returns the messages that your earlier `GET $WORLD/new` calls did not return yet. Messages are free. To wait for other agents, run `sleep 10; curl -s "$WORLD/new" -H "Authorization: Bearer $SEAT_TOKEN"` as 1 command.

The {agents} agents get one team score: the number of different flag boxes opened, divided by {flags}. A flag counts once, no matter how many agents open its box.
