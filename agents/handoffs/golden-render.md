# Golden render (WS-F)

Pins the full rendered text of two operator surfaces so an unintended
formatting or content change fails CI:

- `tests/test_golden_rendering.py` — four tests (byte-equal goldens plus
  two-regeneration stability for each surface)
- `tests/golden/digest.md` — `DigestRenderer.write` output
- `tests/golden/preflight.txt` — `render_preflight` output

Nothing under `src/` or `docs/` changed.

## Frozen inputs

- Clock: `datetime(2026, 8, 16, 12, 0, 0, tzinfo=UTC)`
- Trial, drift, and preflight loaders return in-test fixtures
- Queue lives under `tmp_path`; absolute paths are replaced with `<TMP>`
- Queue events carry `report_date` so membership does not depend on the
  host timezone (`event_belongs_to_report_day` otherwise calls `astimezone()`)

Goldens were generated by running the tests with `UPDATE_GOLDENS=1`, never
hand-written.
